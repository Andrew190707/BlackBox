========================================================
PROJECT ARCHITECTURE
========================================================

The Trust Graph represents TRUST RELATIONSHIPS.

It DOES NOT represent file permissions.

The Enterprise Access Manager is already responsible for

• File permissions
• RBAC
• Authorization
• Policy violations

DO NOT move these responsibilities into the Trust Graph.

Instead the Trust Graph should VISUALLY REACT to events occurring in the Enterprise Access Manager.

Keep both systems independent while allowing them to communicate.

========================================================
OBJECTIVE
========================================================

Transform the Trust Graph into the central visualization engine of BlackBox.

The graph should become a live operational map that displays how trust flows through the enterprise and how it changes during attacks, containment and recovery.

The graph should feel alive.
